# 📰 TechNews Today

![Status](https://img.shields.io/badge/status-em_desenvolvimento-blue)

O **TechNews Today** é um portal moderno de notícias e atualizações do mundo da tecnologia, desenvolvimento de software, inteligência artificial e inovação. O objetivo do projeto é fornecer uma interface rápida, intuitiva e responsiva para que os usuários acompanhem as principais novidades do setor em tempo real.

---

## 🚀 Funcionalidades

- 📬 **Notícias em Destaque:** Seção dedicada para as notícias mais recentes e relevantes.
- 🔍 **Busca de Artigos:** Pesquisa rápida de matérias por palavras-chave.
- 🏷️ **Categorização:** Filtro de notícias por temas (IA, Programação, Gadgets, Cybersegurança, Mercado, etc.).
- 📱 **Layout Responsivo:** Experiência otimizada para desktops, tablets e dispositivos móveis.
- 🌓 **Modo Escuro / Claro:** Alternância de tema para melhor conforto visual (Dark/Light Mode).
- ⚡ **Carregamento Rápido:** Interface leve otimizada para alto desempenho.

---

## 🛠️ Tecnologias Utilizadas

O projeto utiliza as seguintes tecnologias e ferramentas:

- **Frontend:** [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML), [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS), [JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) *(ou React / Next.js / Vite)*
- **Estilização:** Tailwind CSS / CSS Modules
- **Consumo de Dados:** Fetch API / Axios para integração com APIs de notícias
- **Controle de Versão:** [Git](https://git-scm.com/) & [GitHub](https://github.com/)
